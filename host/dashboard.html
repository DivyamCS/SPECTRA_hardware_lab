The simulated board is rv32sim: exact results, approximate cycles. Runs appear on the Runs tab and can be compared like board runs.

Every demo case: set the switches, then press BTNC

Up = the switch is on. CONFIG is read at reset, so set the switches first and then press BTNC. After each run the 7-segment display tours the results, 3 s per item: cycles (thousands), then for each core the I-cache hit %, D-cache hit % and CPI, and with two cores each core's arbiter wait %. LED15:14 and LED11 show which item it is, with the same meaning as the manual browser; LED13 = core 1; LED10 = tour on. Moving SW15:14 or pressing BTNL / BTNR switches to the manual browser; BTNU starts the tour again. "board" results were measured on the FPGA (docs/results/board_regress.md); the other cases show their numbers on the Live tab after the run.
